| Pixel match vs cooldock.app | `scripts/build-app.sh release && scripts/pixel-diff.sh` → `build/pixel-report/report.html` | 74/74 site frames (73 widget images + the contact card from the site's widget atlas) exact size · mean match 99.89 % at 8 % colour fuzz (median 99.91 %, strict 3 %: 99.77 %) · every frame ≥ 99.51 % (lowest: contactCard 99.51 %, resampled from the atlas, and nowPlaying 99.59 %, whose title is caught mid-scroll and resampled by the browser; every other frame ≥ 99.70 %; crops in [pixel-residue/](pixel-residue/)). Flat-area match (non-edge pixels only, where a ≤ 1 px shift cannot cause a difference): mean 99.95 %, min 99.48 % (contactCard). Shift-tolerant match (a render pixel matches if any reference pixel within 1 px matches it): mean 99.82 %, min 98.53 % (screenshots). All counts agreed exactly with an independent NumPy re-implementation on five frames |
