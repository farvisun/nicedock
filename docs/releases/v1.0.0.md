The first public release of NiceDock: a second Dock for macOS with 111 native widgets.

**Highlights**
- Widgets for clocks and focus timers, calendars and reminders, weather, stocks and crypto, system stats, quick toggles,
  files, media, connected services (Stripe, GitHub, Plausible, Shopify, …) and AI usage.
- Seven layouts: swap with the macOS Dock, reveal on hover, fixed in any corner, replace the Dock, or floating.
- Up to eight profiles, a full Settings window with twelve panes, six dock styles including Liquid Glass.
- Ten languages. Persian and Arabic switch the interface to right-to-left, with the Estedad typeface, the Solar Hijri
  calendar and native digits.
- Local-first: no account, no telemetry; tokens stay in the macOS Keychain.
- Optional AI Assistant (MCP server) for Claude, Codex, Cursor and other clients. Off by default and read-only until
  you allow changes.

**Install**
1. Download `NiceDock.dmg` and drag NiceDock into Applications. Requires macOS 14 Sonoma or later on Apple silicon.
2. NiceDock is ad-hoc signed and not notarized by Apple, so macOS stops the first launch. Open
   System Settings › Privacy & Security and click **Open Anyway**, or run
   `xattr -dr com.apple.quarantine /Applications/NiceDock.app` once.

Weather, stock and crypto widgets need network access; if a firewall such as Little Snitch asks, allow NiceDock.
