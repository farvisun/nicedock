NiceDock now runs on Intel Macs too, and installs with Homebrew.

**New**
- **Intel Macs**: NiceDock is now one universal app for Apple silicon and Intel (macOS 14 or later).
- **Homebrew**: `brew install --cask farvisun/tap/nicedock`. Each release updates the cask.
- **Open source license**: NiceDock is MIT licensed. The bundled Estedad typeface stays under the SIL Open Font License.

**Install**
1. Download `NiceDock.dmg` and drag NiceDock into Applications, or use Homebrew as above.
2. NiceDock is ad-hoc signed and not notarized by Apple, so macOS stops the first launch. Open
   System Settings › Privacy & Security and click **Open Anyway**, or run
   `xattr -dr com.apple.quarantine /Applications/NiceDock.app` once.

Already on 1.1.0: NiceDock offers this update itself (Check for Updates… in the menu bar menu).
