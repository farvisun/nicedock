NiceDock now keeps itself up to date.

**New**
- **Updates in the app**: NiceDock checks the latest GitHub release once a day and offers to install a new version
  in place, with its release notes. Check by hand with **Check for Updates…** in the menu bar menu, the app menu or
  Settings › About, where you can also turn the daily check off. Updates are verified with an EdDSA signature
  (Sparkle) before they are installed.

**Install**
1. Download `NiceDock.dmg` and drag NiceDock into Applications. Requires macOS 14 Sonoma or later on Apple silicon.
2. NiceDock is ad-hoc signed and not notarized by Apple, so macOS stops the first launch. Open
   System Settings › Privacy & Security and click **Open Anyway**, or run
   `xattr -dr com.apple.quarantine /Applications/NiceDock.app` once.

Coming from 1.0.0: this download is needed once; later versions arrive through the updater.
